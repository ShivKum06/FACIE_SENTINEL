    API test quick reference

    BOLA / IDOR

    Check whether a user can reach another user's object or resource using a predictable identifier without permission checks.

    🔑

    Broken Authentication

    Verify tokens, refresh flows, and session sharing are not trivial to bypass or replay across accounts.

    Unrestricted Resource Consumption
